# Achille ImmoSwipe

Application de définition des critères de recherche, intégrée au site de l'agence.

- **Lien à communiquer (et cible du QR code)** : https://achille-immobilier.fr/fr/immoswipe
- **QR code** : `qr-immoswipe.png`
- **Fichier de l'application** : `index.html` (copie identique dans `swipe-apimo/index.html`, adresse chargée par la page du site). Ne pas supprimer ni renommer ces fichiers, ne pas rendre ce dépôt privé : la page du site en dépend.
- Ouverte directement, l'adresse github.io renvoie vers la page du site (ajouter `?direct=1` pour l'afficher sans renvoi).
- Les modifications se font dans l'artefact Claude « Achille ImmoSwipe », puis sont publiées ici.
